# Research and engineering philosophy

**"Honest results beat impressive results."** The Quantum-RL dissertation is the load-bearing example: of 4 quantum-inspired methods, 1 worked conditionally (Interference Ensemble on state-based DMControl, 36–47% MSE reduction p<0.008 with Bonferroni correction) and 3 returned null or catastrophic results (Superposition Buffer: −158% to −630%; Tunneling: no effect; Entanglement Layer: no effect). All four were reported. The Interference Ensemble's conditional failure on Atari visual RL (−132% to −414%) is also disclosed on the README front page. Saurabh added a uniform-ensemble ablation **after** seeing the positive result — to control for "is this just ensembling?" — which is the inverse of the usual incentive.

**Bonferroni + Mann-Whitney U is the default.** 200 experiments, 5 methods × 5 seeds × 8 environments, non-parametric test, α = 0.05 / 6 ≈ 0.0083. The minimum achievable p with n = 5 is 0.00794, so when the result says p<0.008 it means "the test was as strong as the sample allowed."

**Risk-Manager-as-veto.** The Trading Agent's architectural commitment: the Risk Manager agent holds binding veto authority over the decision agent's output (Kelly + Fixed Fractional sizing, VaR, drawdown cap, daily-loss cap, concentration check). In `coordinator.py:274`, the flow proceeds only if `risk_assessment.get('approved')` is True; lines 283–295 enforce capital % and stop-width caps that can flip `approved` to False post-hoc. This is a concrete instance of one model auditing another.

**Negative controls are the differentiator.** The clarification benchmark adds 500 clear-control prompts so that an over-clarifying agent is penalized — the false-positive control is the contribution. The pre-emptive disclosure of dataset confounds (length: Cohen's d = 1.601; BoW: 76.2% baseline accuracy without semantics) in the README "Anti-Patterns We Avoided" section is part of the research-quality signal.
